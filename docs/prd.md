# Untangle(가칭) 웹 프로토타입 MVP PRD

> 원본 기획: `docs/untangle-mvp-plan.md` · 웹 프로토타입은 1~2주 사용 검증용이며, 최종 목표는 iPhone 앱이다.

## 🎯 핵심 정보

**목적**: 머릿속 생각을 분류 부담 없이 한 줄씩 쏟아붓고, 나중에 걱정 / 해야 할 일로 간단히 정리한다.
**사용자**: 생각이 많아 할 일 앱의 입력과 분류 단계에서 막히는 ADHD 성향의 개인 사용자(본인 1인 사용).

## 🚶 사용자 여정

```
1. 브레인 덤프 (첫 화면)
   ↓ 한 줄씩 입력 (아무것도 묻지 않음)
2. 브레인 덤프 목록에서 항목 하나를 선택해 분류
   ↓ 분기
   ├─ 걱정 ─────────→ 걱정 페이지
   │                    ↓ [행동으로 바꾸기] → 걸리는 시간·언제 선택 → 해야 할 일 페이지
   ├─ 해야 할 일 ───→ 걸리는 시간·언제 선택 → 해야 할 일 페이지
   ├─ Archive ──────→ Archive 페이지
   └─ 삭제 ─────────→ 목록에서 사라짐 (직후 되돌리기 가능)
3. 해야 할 일 페이지에서 완료 → Archive 페이지
4. 대시보드에서 오늘 할 일과 미분류 개수를 한눈에 확인 → 각 페이지로 이동
```

## ⚡ 기능 명세

### 1. MVP 핵심 기능

| ID | 기능명 | 설명 | MVP 필수 이유 | 관련 페이지 |
|----|--------|------|-------------|------------|
| **F001** | 빠른 입력 | 한 줄 입력 후 확인하면 바로 추가되고 입력창은 유지된다. 여러 줄을 붙여넣으면 줄마다 항목이 된다. 우선순위·날짜·태그는 묻지 않는다 | 입력 마찰 0이 이 앱의 핵심 가치 | 브레인 덤프, 대시보드 |
| **F002** | 항목 분류 | 브레인 덤프 항목을 걱정 / 해야 할 일 / Archive / 삭제 중 하나로 보낸다. 삭제 직후에는 짧게 되돌릴 수 있다 | 분류를 나중에 한 번에 하나씩 하게 하는 흐름 검증 | 브레인 덤프 |
| **F003** | 해야 할 일 설정 | 걸리는 시간(Quick 10분 이하=초록, Focus 30분 이상=노랑)과 언제(오늘 / 이번 주 / 언젠가)를 고른다. 이후 바꿀 수 있다 | 노트의 형광펜 구분을 디지털화하는 핵심 UX | 브레인 덤프, 걱정, 해야 할 일 |
| **F004** | 걱정 보관과 행동 전환 | 걱정을 그대로 보관하거나, 행동 한 줄을 입력해 해야 할 일로 바꾼다. 바꾼 걱정에는 "행동으로 옮김"이 표시된다 | 걱정→행동 변환의 효과 검증 | 걱정 |
| **F005** | 해야 할 일 보기와 완료 | 오늘 / 이번 주 / 언젠가로 묶어 보여 주고, 완료하면 Archive로 이동한다 | 분류한 일을 실제로 꺼내 쓰는 단계 | 해야 할 일, 대시보드 |
| **F006** | Archive 보관 | 끝낸 일과 치워 둔 생각을 지우지 않고 보관한다. 브레인 덤프로 되돌리거나 완전히 삭제할 수 있다 | 안전망이 있어야 마음 편히 분류한다 | Archive |
| **F007** | 대시보드 요약 | 오늘 해야 할 일(Quick/Focus 색 표시)과 미분류 개수를 한 화면에 보여 준다 | iOS 위젯의 "열지 않고 본다"를 웹에서 검증 | 대시보드 |

### 2. MVP 필수 지원 기능

| ID | 기능명 | 설명 | MVP 필수 이유 | 관련 페이지 |
|----|--------|------|-------------|------------|
| **F010** | 기기 내 데이터 저장 | 모든 항목을 사용하는 기기의 브라우저에만 저장한다. 새로고침해도 유지된다 | 로그인·서버 없이 1~2주 사용하려면 필요 | 브레인 덤프, 걱정, 해야 할 일, Archive, 대시보드 |

### 3. MVP 이후 기능 (제외)

- AI, 우선순위, 프로젝트, 태그
- 캘린더, 정확한 마감 시간, 반복 일정
- 알림, 통계
- 로그인(인증), 서버, 소셜 기능

## 📄 페이지별 상세 기능

### 브레인 덤프

> **구현 기능:** `F001`, `F002`, `F003`, `F010` | **메뉴 위치:** 내비게이션 첫 번째(첫 화면)

| 항목 | 내용 |
|------|------|
| **역할** | 생각을 가장 빠르게 꺼내는 입력 공간이자, 미분류 항목을 정리하는 곳 |
| **진입 조건** | 앱을 열면 가장 먼저 보이는 화면. 내비게이션과 Archive의 "되돌리기"로도 진입 |
| **사용자 행동** | 생각을 한 줄씩 입력하고, 나중에 항목 하나를 골라 걱정 / 해야 할 일 / Archive / 삭제로 보낸다 |
| **기능 목록** | • 항상 보이는 입력창, 연속 입력 가능, 여러 줄 붙여넣기 시 항목 분리 (F001)<br>• 항목별 분류 버튼 4개, 삭제 직후 되돌리기 (F002)<br>• 해야 할 일 선택 시 걸리는 시간·언제 선택 (F003)<br>• 항목 저장 유지 (F010) |
| **구현 기능 ID** | F001, F002, F003, F010 |

### 걱정

> **구현 기능:** `F003`, `F004`, `F010` | **메뉴 위치:** 내비게이션 두 번째

| 항목 | 내용 |
|------|------|
| **역할** | 걱정을 쌓아 두지 않고 눈에 보이는 곳에 내려놓는 곳 |
| **진입 조건** | 브레인 덤프에서 걱정으로 분류, 또는 내비게이션 |
| **사용자 행동** | 걱정을 읽고 그대로 두거나, 행동 한 줄을 적어 해야 할 일로 바꾼다 |
| **기능 목록** | • 걱정 목록 보기 (F004)<br>• **행동으로 바꾸기**: 행동 입력 후 걸리는 시간·언제 선택 (F004, F003)<br>• 바꾼 걱정에 "행동으로 옮김" 표시 (F004)<br>• Archive 또는 삭제 (F004)<br>• 항목 저장 유지 (F010) |
| **구현 기능 ID** | F003, F004, F010 |

### 해야 할 일

> **구현 기능:** `F003`, `F005`, `F010` | **메뉴 위치:** 내비게이션 세 번째

| 항목 | 내용 |
|------|------|
| **역할** | 분류한 할 일을 오늘 / 이번 주 / 언젠가로 묶어 보여 주고 실제로 처리하는 곳 |
| **진입 조건** | 브레인 덤프나 걱정에서 해야 할 일로 보낸 뒤, 또는 내비게이션 |
| **사용자 행동** | 목록에서 지금 할 일을 고르고, 끝나면 완료하며, 필요하면 시간·시점을 바꾼다 |
| **기능 목록** | • 시점별 목록, Quick/Focus 색과 글자 표시 (F005)<br>• 완료 시 Archive로 이동 (F005)<br>• 걸리는 시간·언제 변경 (F003)<br>• 항목 저장 유지 (F010) |
| **구현 기능 ID** | F003, F005, F010 |

### Archive

> **구현 기능:** `F006`, `F010` | **메뉴 위치:** 내비게이션 네 번째

| 항목 | 내용 |
|------|------|
| **역할** | 끝낸 일과 치워 둔 생각을 지우지 않고 보관하는 안전망 |
| **진입 조건** | 완료 또는 Archive 분류 후, 또는 내비게이션 |
| **사용자 행동** | 보관한 항목을 둘러보고, 필요하면 되돌리거나 완전히 삭제한다 |
| **기능 목록** | • 최근 순 목록 (F006)<br>• 브레인 덤프로 되돌리기 (F006)<br>• 완전히 삭제 (F006)<br>• 항목 저장 유지 (F010) |
| **구현 기능 ID** | F006, F010 |

### 대시보드

> **구현 기능:** `F001`, `F005`, `F007`, `F010` | **메뉴 위치:** 내비게이션 다섯 번째

| 항목 | 내용 |
|------|------|
| **역할** | iOS 위젯의 대체. 필요한 것만 한 화면에서 보는 곳 |
| **진입 조건** | 내비게이션 |
| **사용자 행동** | 오늘 할 일을 확인하고, 미분류가 쌓였는지 보고, 생각이 나면 바로 입력한다 |
| **기능 목록** | • 오늘 해야 할 일 목록, Quick/Focus 색 표시, 완료 (F007, F005)<br>• 미분류 개수 숫자 하나, 브레인 덤프로 이동 (F007)<br>• 입력창 (F001)<br>• 항목 저장 유지 (F010) |
| **구현 기능 ID** | F001, F005, F007, F010 |

## 🛠️ 기술 스택 (초안)

기술은 스타터 킷 단계에서 확정한다. 아래는 현재 `my-app`에 설치된 환경 기준의 초안이다.

- **Next.js 16**(App Router), **React 19**, **TypeScript 5** - 화면과 라우팅
- **Tailwind CSS 3.4**, **shadcn/ui**, **Lucide React** - 스타일과 UI 컴포넌트 (새 프로젝트에서는 Tailwind v4 검토)
- **브라우저 localStorage** - 데이터 저장 (서버, DB, 로그인 없음)
